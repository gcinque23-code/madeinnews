# Made in News

Pagina Instagram di notizie italiane: [@madeinnews.it](https://www.instagram.com/madeinnews.it/).

- `REGOLE.md`: regole editoriali, grafiche, foto, voce e orari.
- `brand/`: logo e foto profilo.
- `engine/`: generatori di post (Playwright), reel motion graphic ed explainer con voce ElevenLabs.
- `tools/`: ricerca di foto con licenza libera (Wikimedia Commons, Openverse).
- `contenuti/AAAA-MM-GG/`: post, reel e didascalie pubblicati ogni giorno.

Nessuna chiave è salvata qui: le credenziali (ElevenLabs, Instagram) sono nelle impostazioni sicure dell'ambiente.
